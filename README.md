# 志す方へ ― 後醍醐天皇 隠岐配流と脱出（西ノ島の伝承より）

Meta Quest 2 以降のブラウザで遊べる WebXR の 3D VR 体験です。元弘二年（1332）に隠岐へ流された後醍醐天皇が、翌年閏二月に島を脱出するまでを、**西ノ島に残る伝承**を軸にたどります。

- アプリのインストールは不要です。Quest のブラウザでページを開き「VRで体験する」を押します。
- PC のブラウザでも「PCで体験する」から最後まで遊べます（マウスとキーボード）。
- 3D モデル・音声ファイルは使っていません。建物・人物・海・空・音楽・効果音はすべてプログラムで生成しています。外部から読み込むのは Three.js（jsDelivr CDN）とフォントの Shippori Mincho（Google Fonts）だけです。

## 章の構成と伝承との対応

| 章 | 舞台 | 体験すること | 主な出典の札 |
|---|---|---|---|
| 序章　配流の海 | 隠岐へ向かう船 | 京を発つまでの経緯。忠顕と言葉を交わし、霧の向こうの島影を見る | 鳥取県の歴史解説・『太平記』・『増鏡』 |
| 第一章　仁夫里の浜 | 知夫里島 | 仁夫里浜に上陸 → 赤ハゲ山の仁夫里坊へ登る → 古海坊の扁額に「松尾山松養寺」と記す | 知夫里島の伝承・碧風館の展示順路 |
| 第二章　黒木御所 | 西ノ島・別府 | 三位の局を訪ねる／千福寺で毘沙門天に祈る／縁側で釣舟を眺め「志す方を問はばや」の歌／港のそばの見付島と隠岐判官館の監視。季節が巡り、義綱が戻らぬ夜、局の輿で御所を出る決意 | 西ノ島の伝承・『増鏡』・『太平記』 |
| 第三章　闇にまぎれて | 別府 → 小向 | 局の輿で門を出る → 名も知れぬ島の男の案内で、判官館の南の浜沿いを巡回の松明を避けて西へ抜ける → 約3km西、美田湾の東岸の小向へ → 御腰掛けの石で舟を待つ → 木村家に愛染明王の懸仏を授ける | 『太平記』・西ノ島の伝承・焼火神社の資料 |
| 第四章　笏の江 | 小向 → 赤ノ江 → 赤崎 | 小舟で美田湾を南へ下り、湾を南西へ渡る。西岸の赤ノ江の手前で笏が海へ落ちる（地名由来）。岸沿いに赤崎の沖の船へ（実際は約4kmの道のりを、場面を区切って省略） | 西ノ島の伝承 |
| 第五章　風を待つ | 海上 | 船上で身分を明かす → 追手から船底に隠れ、乾魚の俵の下で息をひそめる → 凪いだ海に仏舎利を捧げ、風が変わる | 『太平記』 |
| 終章　志す方へ | 伯耆の浜 | 名和長年・船上山・綸旨・京への帰還。終わると「タイトルに戻る」だけを表示 | 鳥取県の歴史解説・『増鏡』 |

### 史実・伝承の扱い

- 語りの字幕には、右下に**出典の札**（例：「西ノ島の伝承（観光協会の地図）」「『太平記』」）を付けています。
- 天皇の居所の国分寺説、出航地（見尾の湊／やすぎの津、千波湊と赤崎）、上陸地（名和湊／稲津の浦）の違いは、作中の語りでそのまま「書物によって異なる」と伝えています。
- 焼火神社の資料にある「赤崎の伝説」（判官が密使を送り、追うふりをした異伝）は、日付が一般の脱出時期と一致しないため本筋には混ぜず、本筋には入れていません（本文は `src/story/sources.js` の「別伝」に残してあります）。
- 登場人物の台詞はゲームのための創作です。起動画面の「この体験について」にも明記しています。

### 地形と位置関係（地図にもとづく）

別府・小向・赤ノ江／赤崎の舞台は、国土地理院の標高データ（DEM10B、10m メッシュ）から実寸で作っています。史跡の位置は国土地理院・OpenStreetMap の地図で確認しました。

| 場所 | 実際の位置関係 |
|---|---|
| 黒木御所跡 | 別府港の北東、湾に突き出した小丘（標高約39m）。湾は御所の南〜南東に開く |
| 見付島 | 別府港のすぐ南の小島。御所からは湾をはさんで南南西へ約660m |
| 隠岐判官館跡 | 御所の西北西約220m、湾を見下ろす台地（標高約14m） |
| 小向 | 別府から西へ約3km、美田湾の東岸 |
| 赤ノ江・赤崎 | 小向から湾を南西へ約4km。赤ノ江は湾の西岸の入り江、赤崎はその南の小さな岬 |

三位の局屋敷跡・千福寺御座所跡は正確な位置が分からないため、御所の麓に置いています。知夫里島（第一章）と伯耆（終章）の地形は、まだ地図にもとづかない創作の地形です。

地形データは `tools/make_mapdata.py` で作り直せます（`python tools/make_mapdata.py`。numpy が必要。取得したタイルは `tools/.cache` に保存）。

## 操作方法

### Meta Quest（コントローラー）
| 操作 | 動作 |
|---|---|
| 地面を指す → トリガー | 指した所に青い輪が出て、そこへ移動（移動できる場面のみ） |
| トリガー | 光る印（◆）を指して選ぶ。字幕が出ているときは字幕を送る |
| スティックを前に倒す → 離す | 弧で行き先を選んで移動（こちらでも可） |
| スティック左右 | 30° ずつ向きを変える |
| グリップを離す | 手に持った物（懸仏・仏舎利）を差し出す・海へ離す |
| A / X | 字幕を送る |
| B / Y | いまの目的を表示（左手首にも常時表示） |

ハンドトラッキングでは、指でつまむ動作がトリガーの代わりになります。

### PC
ドラッグで見回す／クリックで選ぶ／地面をクリックしてそこへ移動／W A S D・矢印キーで歩く／スペース・Enter で字幕送り／O で目的を表示。

### 目的と案内
- いまの目的は、PC では画面左上、VR では左手首に表示されます（B / Y ボタン・O キーで目の前にも表示）。
- いくつかの目的がある場面では「目的（2/4）」のように進み具合を示し、済んだものに ✓ が付きます。
- 「〜を見る」目的では、見る先に目の印の輪が出ます。見つめている間、輪が金色に満ちていきます。見る先が視界の外にあるときは、視野の端に矢印が出てその方向を示します。

### 酔い対策
- 移動はテレポート方式、向きはスナップターン（連続回転なし）。
- 起動画面の「VRでスティックを倒して歩く」を選ぶと、左スティックで歩けます（歩いている間は視野の周辺を暗くします）。
- 移動できる場面になると、実際に一度移動するまで移動のしかたを表示し続けます。
- 舟・輿で運ばれる場面は低速で、視野の周辺を暗くします（起動画面の設定で切れます）。
- 舟が揺れる表現は船体だけに付け、視点（地平線）は揺らしません。

## 動かし方

WebXR は **HTTPS**（または `localhost`）で配信されたページでしか動きません。

### 1. PC で試す

```bash
node server.js
```

ブラウザで http://localhost:8080 を開き「PCで体験する」。Node.js 以外の依存はありません（`npm install` 不要）。

### 2. Quest 実機で試す（ケーブルなし・同じ Wi‑Fi）

PC と Quest を同じ Wi‑Fi につなぎ、PC で次を実行します。

```bash
node server.js 8080 --https
```

表示された `https://192.168.x.x:8443` を Quest のブラウザで開きます。自己署名の証明書なので最初に「この接続ではプライバシーが保護されません」と出ます。「詳細設定」→「（アドレス）にアクセスする」で進み、「VRで体験する」を押します。

- 証明書は初回起動時に `.cert/` へ自動で作られます（Git for Windows の openssl を使用）。PC の IP が変わると作り直します。
- `.cert/`・`tools/`・`server.js` などは配信しません。
- 開けないときは、Windows のファイアウォールで Node.js の受信が「プライベート ネットワーク」で許可されているか確認してください。

### 3. 離れた場所の Quest で試す（インターネット経由の一時URL）

PC で次を実行すると、ゲームのサーバーと Cloudflare の一時URL（トンネル）がまとめて起動します。

```bash
powershell -ExecutionPolicy Bypass -File tools/start-remote.ps1
```

表示された `https://〜.trycloudflare.com` を Quest のブラウザで開きます。正式な証明書なので警告は出ません。

- 使うには `cloudflared`（Cloudflare 公式）が必要です。`%LOCALAPPDATA%\Programs\cloudflared\cloudflared.exe` に置くか、`winget install --id Cloudflare.cloudflared` で入れます。
- URL は起動するたびに変わります。PC とこの画面が動いている間だけ使え、Ctrl+C で止まります。
- URL を知っている人は誰でも開けます（配信するのはゲームのファイルだけです）。

### 4. Quest 実機で試す（USB 接続・開発者モード）

Quest を開発者モードにして USB で PC につなぎ、上のサーバーを起動したまま次を実行します。

```bash
adb reverse tcp:8080 tcp:8080
```

Quest のブラウザで `http://localhost:8080` を開き「VRで体験する」。localhost なので HTTPS なしで WebXR が使えます。

### 5. Quest 2 だけで遊ぶ（PC なし・公開してオフライン対応）

PC を起動しておかなくても Quest 2 単体で遊べるよう、ゲームは次のようになっています。

- three.js を同梱（`vendor/three/`）しているので、外部の CDN に頼りません。
- サービスワーカー（`sw.js`）が、初回に開いたとき必要なファイルをすべて Quest に保存します。2 回目からは、ネットにつながっていなくても遊べます（字幕の明朝体フォントも、一度表示したものは保存されます）。
- アプリとしての情報（`manifest.webmanifest`・`icons/`）を持っているので、Quest のブラウザからアプリとして追加できます。

公開の手順：

```bash
npm run build
```

できた `dist/` フォルダの中身を、HTTPS の静的ホスティングにそのまま置きます（GitHub Pages、Cloudflare Pages、Netlify など）。その URL を Quest のブラウザで一度開き、「VRで体験する」を押します。

- タイトル画面（2D の起動画面と VR のタイトルメニュー）に「ver 1.0.0（コミット・日付）」のように版を表示します。版の番号は `package.json` の `version` で、公開するたびにコミットと日付が自動で入ります（手元で動かしているときは `dev`）。
- ソースを直したら `npm run build` をやり直して置き直します。ファイル一覧（`precache.js`）の版が変わり、Quest に保存したものも次に開いたとき新しくなります。
- 初回だけはネット接続が必要です（全体で約 1.3 MB とフォント）。

## 開発用 URL パラメータ

| パラメータ | 内容 |
|---|---|
| `?ch=3` | 起動画面の章選択を第三章にする |
| `?autostart=pc` | 起動画面を飛ばして PC モードで開始 |
| `?auto=1` | 自動進行（選択・視線待ちを自動で済ませる。通しの動作確認用） |
| `?fly=1` | PC モードで自由飛行（W A S D + Q/E で上下） |
| `?quality=high` | 画質を指定（`standard` / `high` / `auto`） |
| `?speed=2` | 時間の進みを速める |

## グラフィックと画質設定

画像ファイルは使わず、質感はすべてプログラムで作っています。

- 地形：標高・傾き・ノイズで草地・森（樹冠）・土・岩・砂浜・濡れた砂を塗り分け、谷は暗くしています。道は地面そのものに土の色として描きます。
- 海：岸からの距離をもとに浅瀬の青緑と波打ち際の白波を描き、さざ波は法線テクスチャで表現しています。
- 空：時間帯ごとの色と、陰影のある雲。
- 建物：木目・黒木の樹皮・茅葺き・畳・石垣の質感。
- 植物：風に揺れる黒松・照葉樹・草むら、磯の岩。
- 人物：裾や袖口の重ねの色（襲）と、絵巻物風の顔（引目鉤鼻）。

起動画面の「設定・章を選ぶ」で画質を選べます（既定は「自動」＝ Quest 2 では標準、それ以外は高）。

| 画質 | 内容 | 1 画面あたりの三角形（PC 表示で計測・最大） |
|---|---|---|
| 標準（Quest 2 向け） | 影なし、木と草を少なめ | 約 16〜22 万 |
| 高（Quest 3 以降・PC） | プレイヤーのまわりに影、木と草を多め | 約 30〜35 万 |

VR では左右の目で 2 回描くので、実際の負荷はこの約 2 倍です。灯りは点光源 2 つまでに固定しています（シェーダーの再コンパイルによるカクつきを防ぐため）。

**Quest 2 向けの調整**

- 「自動」は Quest 2・初代 Quest を見分けて標準にします（影なし、木・草を少なめ、周辺部の解像度を下げる固定フォービエーションを最大）。
- VR 中はフレーム時間を見張り、72Hz に間に合わない状態が 3 秒続いたら、草 → 磯の岩と遠く（260m 先）の木の順に省いて軽くします（場面が暗転している間は測りません）。
- 海面のうち舟の下を抜く処理は、近くの舟だけを調べるようにしてあります。
